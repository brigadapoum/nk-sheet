# Новое королевство — лист Жука

Модуль для Foundry VTT 13 и системы **Into the Odd 3.1.x**: доработки листа персонажа под правила кампании «Новое королевство».

## Установка

Foundry → Add-on Modules → Install Module → поле **Manifest URL**:

```
https://github.com/brigadapoum/nk-sheet/releases/latest/download/module.json
```

На Sqyre: страница игры → Manage Game → Manage Modules → установка по manifest URL. Затем включить модуль в мире (Manage Modules внутри Foundry).

## Что умеет

**Передача предметов.** Строку из инвентаря можно перетащить на лист другого Жука — предмет переносится, а не копируется. Для стопок спрашивает, сколько отдать, и подливает к такой же стопке получателя. Если лист чужой, передачу выполняет клиент мастера (мастер должен быть в игре). В чат пишется, кто кому что отдал, и предупреждение, если получатель перегружен. Перетаскивание на собственный лист больше не дублирует предмет.

**Ячейки (по Кодексу, раздел 4 «Инвентарь»).**
- Ёмкость = максимальная Сила.
- У каждого предмета на его листе появился блок «Новое королевство»: сколько ячеек занимает одна штука (по умолчанию 1), где лежит, амулет ли это.
- Где лежит: в мешке (занимает ячейки), в лапках и в карманце (не занимают), на шее (только амулеты, не занимают ячеек инвентаря, но занимают ячейки амулетов).
- Кнопка с иконкой в строке предмета перекладывает его по кругу: мешок → лапки → карманец (→ шея для амулетов).
- Янтарь (поле «пенни»): каждые 100 — 1 ячейка.
- Стопка из N штук занимает N × ячеек.

**Предупреждения** в плашке над инвентарём: перегруз (отряд вдвое медленнее), больше 2 громоздких (HP 0 до Длительного отдыха), больше 2 вещей в карманцах, громоздкое или крупное в карманце, перебор ячеек амулетов (1 + по одной за уровень).

Модуль заодно включает прокрутку вкладки «Инвентарь» — правило из Custom CSS можно удалить.
