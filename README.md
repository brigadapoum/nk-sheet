# Новое королевство — лист Жука

Модуль для Foundry VTT 13 и системы **Into the Odd 3.1.x**: доработки листа персонажа под правила кампании «Новое королевство».

## Установка

Foundry → Add-on Modules → Install Module → поле **Manifest URL**:

```
https://raw.githubusercontent.com/brigadapoum/nk-sheet/main/module.json
```

На Sqyre: страница игры → Manage Game → Manage Modules → установка по manifest URL. Затем включить модуль в мире (Manage Modules внутри Foundry).

## Что умеет

**Передача предметов.** Строку из инвентаря можно перетащить на лист другого Жука — предмет переносится, а не копируется. Для стопок спрашивает, сколько отдать, и подливает к такой же стопке получателя. Если лист чужой, передачу выполняет клиент мастера (мастер должен быть в игре). В чат пишется, кто кому что отдал, и предупреждение, если получатель перегружен. Перетаскивание на собственный лист больше не дублирует предмет.

**Ячейки (по Кодексу, раздел 4 «Инвентарь»).**
- Ёмкость = максимальная Сила.
- У каждого предмета на его листе появился блок «Новое королевство»: сколько ячеек занимает одна штука (по умолчанию 1), где лежит, амулет ли это.
- Где лежит: в мешке и надета (броня) — занимают ячейки; в лапках, в карманце и на шее (только амулеты) — не занимают. Надетые амулеты занимают ячейки амулетов.
- Кнопка с иконкой в строке предмета перекладывает его по кругу и **заменяет системную кнопку «экипировать»** (она скрыта, как и галочка «Equipped» в листе предмета):
  - броня: мешок ↔ надета; надетая броня считается в поле «Броня»;
  - оружие: мешок → лапки → карманец; в лапках и в карманце оружие экипировано, появляется бросок урона;
  - прочее: мешок → лапки → карманец (→ шея для амулетов).
- Вещам, которым место ещё не задавали, оно берётся из старой экипировки: надетая броня — «надета», экипированное оружие — «в лапках».
- Янтарь (поле «пенни»): каждые 100 — 1 ячейка.
- Стопка из N штук занимает N × ячеек.

**Предупреждения** в плашке над инвентарём: перегруз (отряд вдвое медленнее), больше 2 громоздких (HP 0 до Длительного отдыха), больше 2 вещей в карманцах, громоздкое или крупное в карманце, перебор ячеек амулетов (1 + по одной за уровень).

**Деньги.** Поле «пенни» называется «Янтарь», «гульдены» — «Опыт», шиллинги скрыты.

Модуль заодно включает прокрутку вкладки «Инвентарь» — правило из Custom CSS можно удалить.

**Инвентарь (с 0.3).** Вещи в лапках, карманцах, на шее и надетая броня собираются в блок «При себе» наверху, ниже — «В мешке». Янтарь показан отдельной строкой мешка со своими ячейками (0–99 → 0, 100–199 → 1, 200 → 2). Ячейки выделены янтарной плашкой.

**Вид предмета (с 0.3).** На листе предмета — три галочки: амулет, печать, артефакт (системная «Arcana» скрыта). В инвентаре вид показан тонкой цветной рамкой.
- Печать: кнопка-молния «Использовать» пишет карточку в чат, и печать сгорает (из стопки — одна). Галочка «Многоразовая» — печать остаётся.
- Амулет может иметь заряды («сейчас из максимум»). Тогда молния списывает заряд и пишет в чат. Восстанавливает заряды мастер.

## Лавки (с 0.3)

**Торговец** — любой персонаж, которому мастер поставил галочку «Сделать торговцем» (внизу вкладки «Инвентарь») или выбрал «Сделать торговцем» правым кликом в списке актёров. Его инвентарь — ассортимент.

- На листе торговца (видит только мастер): кнопка «Открыть/Закрыть лавку», сколько он тратит за визит на всю партию (по умолчанию 1000 я) и порог мелочи — не берёт вещи, за которые заплатил бы меньше 5 я.
- На листе товара (видит только мастер): цена, цена продажи (пусто — половина цены), раздел, запас (пусто — без ограничений), «только мастер» (артефакты — по умолчанию). Без цены товар видит только мастер.

**Открыть лавку** можно тремя способами: кнопкой на листе торговца, правым кликом по нему в списке актёров, кнопкой в меню токена (правый клик по токену). Ещё можно перетащить торговца на панель макросов — получится кнопка «открыть/закрыть» в один клик.

При открытии в чате у всех появляется карточка «Зайти в лавку». Пока лавка открыта, игрок может открыть её и двойным кликом по токену торговца.

**Окно лавки**: кто торгует (свой Жук), его янтарь и ячейки; «Купить / Продать»; разделы и «Всё». Клик по названию раскрывает описание.
- Покупка: окошко с количеством, ценой, янтарём и ячейками до/после. Не хватает янтаря — не проводит. Перегруз — предупреждает. Стопки подливаются к своим.
- Продажа: торговец берёт только то, что есть у него в ассортименте (купленное в лавке узнаёт по метке, найденное — по названию), по цене продажи, в пределах кошелька визита. Проданное с ограниченным запасом возвращается ему в запас.
- Сделки выполняет клиент мастера — мастер должен быть в игре. Каждая сделка — карточка в чате. Кнопка «Отменить» на карточке (видит только мастер) возвращает вещи, янтарь, запас и кошелёк.
- Скрытые товары мастер видит в лавке с кнопкой «Выдать» (бесплатно).

API для макросов: `game.modules.get("nk-sheet").api.toggleShop("Мэтр Лампаньон")`, `…api.openShop(...)` — по имени или UUID.
